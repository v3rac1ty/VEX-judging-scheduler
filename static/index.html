No-show recovery

Teams marked No-show in Check-in show up here with the gaps between their matches. New times are suggested from the match schedule loaded in Setup, before eliminations start.

Admin sign-in

Enter the admin PIN. It's shown in the server window when the server starts and saved in data/admin_pin.txt on the server computer. See the README to change it.
